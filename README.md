An intelligent platform designed to help students prepare for campus placements through AI-driven mock interviews, online tests, and company-specific question banks. The system provides a realistic interview experience, monitors test integrity using AI-based proctoring, and generates performance analytics to help students improve their interview readiness.

🚀 Key Features

AI Mock Interviews
Generates role-specific interview questions using Gemini LLM and evaluates candidate responses with structured feedback.

Resume-Aware Questioning
Parses uploaded PDF resumes and generates interview questions based on the candidate’s skills, experience, and projects.

Online Test System
Allows students to attempt placement-style tests and practice company-specific previous year questions.

AI Proctoring & Malpractice Detection
Uses MediaPipe FaceMesh to detect violations such as:

Multiple faces in frame

Absence from screen

Mobile phone usage during tests

Performance Analytics Dashboard
Provides insights for each test and mock interview including:

Technical score

Communication score

Confidence level

Improvement suggestions

🛠 Tech Stack

Frontend: React.js, Bootstrap

Backend: Node.js, Express.js

Database: MongoDB

AI Integration: Gemini LLM

Computer Vision: MediaPipe FaceMesh

🎯 Purpose

This project was developed as a Final Year Engineering Project to create a scalable system that assists students in improving their placement readiness through AI-powered evaluation, practice modules, and performance tracking.
